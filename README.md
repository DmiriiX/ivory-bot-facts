# IVORY-ART — факты об искусстве по четвергам

Работает **точно так же**, как ваш основной бот картин (`ivory_final`).

## Что делает
- **Каждый четверг** публикует 1 интересный факт об искусстве
- Случайное время между **11:00 и 20:00** по Москве
- Одновременно (но независимо) в **Telegram** и в **MAX**
- Кнопка: **«Интересные картины на нашем сайте»** → https://www.ivory-art.com
- После 15 фактов цикл начинается сначала

## Структура (как у основного бота)
```
.github/workflows/post.yml
scripts/post_once.py
posts.json
state.json
README.md
```

## Секреты GitHub
Settings → Secrets and variables → Actions → New repository secret:

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | токен Telegram-бота |
| `CHANNEL_ID` | ID или @username канала Telegram |
| `MAX_BOT_TOKEN` | токен бота MAX (без Bearer) |
| `MAX_CHANNEL_ID` | ID канала MAX |

Можно использовать **те же секреты**, что уже есть в основном репозитории с картинами.

## Как запустить

1. Создайте новый репозиторий на GitHub (или отдельную папку в существующем).
2. Залейте эти файлы.
3. Добавьте 4 секрета (см. выше).
4. Готово — GitHub Actions сам будет запускать скрипт каждый час в нужном окне.

## Ручной тест
1. Откройте `.github/workflows/post.yml`
2. Временно поставьте `FORCE_POST: "1"`
3. Actions → Run workflow
4. Верните `FORCE_POST: "0"`

## Картинки к фактам (по желанию)
В `posts.json` у каждого поста есть поле `"photo": ""`.  
Можно вставить прямую ссылку на картинку (как в основном боте с Tilda) — тогда пост уйдёт с фото.

Без ссылки публикуется только текст + кнопка.
